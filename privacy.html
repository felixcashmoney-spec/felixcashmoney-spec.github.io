3. Strange Knowns Pipeline and Google user data

The Strange Knowns Pipeline is a private tool used only by the channel operator to run the Strange Knowns YouTube channel. It uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data it accesses

  • Information about the Strange Knowns channel and its own videos (titles, descriptions, thumbnails, publishing status).
  • Statistics of the channel's own videos from YouTube Analytics and YouTube Reporting, for example views, watch time and audience retention, and, once the channel is monetized, its revenue.
  • Public information about other YouTube channels and videos (titles, publishing dates, view counts) for topic research, retrieved with an API key without signing in.

How the data is used

Only to publish the channel's videos and to evaluate how they perform, so that future videos can be improved. Aggregated statistics of the channel's own videos may be sent to Anthropic's Claude API to write performance reports for the channel operator; they are not used to train AI models. The data is not sold, not shared with anyone else and not used for advertising.

Storage and deletion

The data is stored in a private database in a private code repository and in the operator's private cloud environment; only the channel operator has access. Access tokens are stored as protected environment variables, never in code. Data obtained from the YouTube API Services is refreshed or deleted as required by the YouTube API Services Developer Policies. To have data deleted, write to the email address above.

Revoking access

Access granted to the Strange Knowns Pipeline can be revoked at any time on the Google security settings page (Third-party apps and services).

Google API Services User Data Policy

The Strange Knowns Pipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
